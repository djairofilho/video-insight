# Frontend

Interface web do Video Insight, reservada para implementação em TypeScript.

## Responsabilidades

- Autenticação do usuário com OAuth2 e PKCE.
- Cadastro e upload direto de vídeos por URL assinada.
- Criação e acompanhamento de jobs.
- Reprodução do vídeo com navegação por timestamps.
- Exibição e exportação de transcrição, resumo e capítulos.

O framework e o gerenciador de pacotes serão escolhidos pelo responsável antes
do início da implementação. O frontend acessará somente o API Gateway.
