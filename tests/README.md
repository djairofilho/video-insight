# Testes entre componentes

Este diretório reúne testes que não pertencem a um único serviço.

- `contract`: compatibilidade dos contratos REST e de eventos.
- `end-to-end`: jornadas completas executadas pelo API Gateway.
- `load`: carga sobre criação e consulta de jobs.

Testes unitários e de integração específicos permanecem dentro de cada
componente.
